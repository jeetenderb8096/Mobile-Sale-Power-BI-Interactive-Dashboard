# Mobile-Sale-Power-BI-Interactive-Dashboard
This Power BI project focuses on analyzing mobile sales performance using interactive visual dashboards. The goal was to transform raw transactional data into insightful visuals that reveal trends, performance metrics, and customer behaviors. The process began with data import from Excel, where multiple datasets were combined and cleaned using Power Query to ensure consistency and reliability. By applying robust data transformation techniques, redundant columns were removed, missing values were handled, and data was shaped for accurate analysis.

![Page_1](https://github.com/user-attachments/assets/4cefa0d3-21c9-4c0e-94c9-0cd9f07fa8cc)


A major part of this project involved creating dynamic measures and KPIs using DAX (Data Analysis Expressions). Key metrics such as Total Sales, Quantity Sold, Average Selling Price, and Total Transactions were calculated to track business performance. In addition, advanced DAX functions were used to build Month-to-Date (MTD) and Year-over-Year (YoY) comparisons, allowing for a clear view of growth patterns and time-based performance analysis. These calculations formed the backbone of the dashboard’s analytical depth.

![Page_2 MTD](https://github.com/user-attachments/assets/41d492ab-8191-4aa5-b85e-c31a87da4313)


Finally, the dashboard design focused on usability and insight delivery. With interactive filters, visual hierarchy, and intuitive charts, users can explore sales by city, brand, model, and payment method. The project showcases proficiency in data modeling, Power Query transformations, DAX calculations, and KPI development, demonstrating a complete end-to-end business intelligence solution. This Power BI dashboard serves as a strong example of transforming raw data into actionable business insights.
